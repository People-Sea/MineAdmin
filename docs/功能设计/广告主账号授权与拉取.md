# 广告主账号授权与拉取

## 1. 功能目标
本功能用于让租户在“广告主账号”中直接发起腾讯广告 OAuth 授权，并把可访问的广告主账号拉回本系统，完成后续项目归属与员工授权的前置准备。

MVP 目标：

- 租户可直接发起授权
- 系统接收 OAuth 回调
- 系统创建授权来源记录
- 系统拉取并选择广告主账号
- 广告主账号可归属到项目

## 2. 适用范围
本功能属于租户侧 `投放账号管理 -> 广告主账号`。

平台侧不直接代替租户做账号授权，仅负责：

- 维护平台应用
- 分配应用给租户

## 3. 关键业务规则
### 3.1 授权前置条件
租户想发起授权，必须满足：

- 当前租户存在已分配应用
- 至少存在一个可用分配应用
- 当前操作人属于该租户

否则直接拒绝发起授权。

### 3.2 产品交互原则
产品上不单独暴露“授权来源记录”菜单。

产品侧只感知两件事：

- 发起授权
- 选择广告主账号

技术侧再通过 `tenant_auth_grant` 保存授权来源、token、过期时间和同步快照。

### 3.3 OAuth 结果处理
本地回调拿到 `authorization_code` 后，不直接把这一步当成“授权完成”。

后端必须继续完成：

- 校验 `state`
- 换取 `access_token / refresh_token`
- 落库 `tenant_auth_grant`
- 调腾讯广告接口拉取广告主账号列表

只有以上步骤成功后，才算进入“可选择广告主账号”状态。

### 3.4 授权来源记录状态
`tenant_auth_grant` 建议保留以下状态：

- `active`
- `expired`
- `revoked`
- `sync_failed`

### 3.5 广告主账号导入规则
当前导入规则：

- 广告主账号先导入到租户
- 再归属到一个或多个项目
- 再授权给员工

不要把“授权来源”“项目归属”“员工授权”混成一个动作。

## 4. 页面与交互
### 4.1 页面入口
租户后台：

- `配置管理`
  - `投放账号管理`
    - `广告主账号`

### 4.2 页面动作
当前建议动作：

- 发起授权
- 查看当前授权状态
- 拉取可访问广告主账号
- 勾选导入广告主账号
- 选择归属项目

### 4.3 页面展示字段
广告主账号列表建议展示：

- 广告主账号名称
- 广告主账号 ID
- 来源授权记录
- 当前状态
- 归属项目
- 可操作员工数
- 最近同步时间

## 5. 数据与状态
### 5.1 依赖表
- `tenant_auth_grant`
- `tenant_ad_account`
- `tenant_project_ad_account`
- `tenant_member_ad_account`

### 5.2 建议导入口径
拉取完成后，不建议直接把腾讯返回数据原样大字段塞入主表。

当前建议：

- 主表保存本地核心检索字段
- 原始返回快照单独存 JSON 字段或快照表
- 最近一次同步时间单独记录

### 5.3 广告主账号状态
广告主账号本地状态建议至少包含：

- `active`
- `disabled`
- `authorization_expired`
- `sync_failed`

## 6. 接口与后端实现约束
### 6.1 后端模块职责
后端需要拆清楚以下职责：

- 授权 URL 生成
- OAuth 回调处理
- token 交换
- 授权来源记录持久化
- 广告主账号拉取与本地入库
- 项目归属与员工授权

### 6.2 实现顺序
建议按以下顺序开发：

1. 生成授权地址
2. 回调接收与 `state` 校验
3. 换 token 并落 `tenant_auth_grant`
4. 拉取广告主账号列表
5. 导入广告主账号
6. 归属项目
7. 授权给员工

### 6.3 当前接口边界
MVP 当前只保证：

- 能完成授权
- 能拉回账号
- 能选择导入
- 能归属项目

当前不在本阶段实现：

- 自动周期性复杂同步平台
- 跨租户共享广告主账号
- 租户自定义 OAuth 应用

## 7. 验收口径
- 租户能发起授权
- 回调后能生成授权来源记录
- 能拉取到可访问广告主账号
- 能选择导入广告主账号
- 能把广告主账号归属到项目
- 未分配或不可用应用时，租户不能发起授权
