# 风起功能设计总览

## 1. 文档目的
本目录用于沉淀“风起（腾讯广告 MVP）”每一个功能的独立细节文档。

当前原则：

- 一个功能对应一份细节文档
- 文档名称使用中文，便于产品、开发、测试统一沟通
- 只记录当前确认方案，不记录已废弃方案
- 细节文档以可直接进入开发为目标，避免空泛描述

## 2. 当前目录结构
- `平台应用管理.md`
- `平台应用分配.md`
- `广告主账号授权与拉取.md`

## 3. 细节文档统一结构
后续新增功能文档时，统一按以下结构编写：

1. 功能目标
2. 适用范围
3. 关键业务规则
4. 页面与交互
5. 数据与状态
6. 接口与后端实现约束
7. 验收口径

## 4. 当前优先级说明
当前 MVP 下一阶段优先推进以下主链路：

```text
平台应用管理
-> 平台应用分配
-> 广告主账号授权与拉取
-> 账号归属项目
-> 账号授权给员工
```

原因：

- 当前租户、项目、员工、登录上下文已具备基础能力
- 腾讯广告 MVP 能否跑通，核心取决于平台应用和广告主账号授权链路
- 后续广告、创意、审核等数据能力，都依赖这条链路先打通
